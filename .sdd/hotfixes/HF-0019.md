## Ursache

CON-0119 wurde nie gegen den Code geprüft: Die Schema-Datei fehlte, TST-0138 stand auf
`planned`. `start()` schrieb `commit: null`, `finalize()` schrieb `git rev-parse --short HEAD`.

## Fix

- `start()` schreibt `commit: ""`, `finalize()` den vollen Hash. `short_commit()` kürzt für
  `sdd status` und `sdd hotfix list` auf 7 Zeichen.
- `.sdd/contracts/data/hotfix-record-schema.schema.json` angelegt. CON-0119 0.2.0 mit INV-06:
  Format von `created`, alte Records (`null`, Kurzhash) bleiben lesbar.
- TST-0138: `tests/contract/test_tst_0138_hotfix_record_schema.py`.
